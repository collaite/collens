# Collens example documents

This directory contains example document projects that can be imported into Collens through the folder drag-and-drop flow.

Existing examples:

- `example2/` — Aladin example with sequential witness folders.
- `sheherazade2/` — Sheherazade example with custom witness folder names.
- `full-functionality-test-cases/` — curated folder for real, permission-safe examples that together exercise the full application workflow.

See `full-functionality-test-cases/README.md` before adding new test cases.
