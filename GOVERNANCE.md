# Governance

This file explains how decisions are made and who maintains the project.

## Roles

- Project/research lead: Elli Bleeker, Huygens Institute.
- Research software/design lead: Jesse Gonzalez, Netherlands eScience Center.
- Maintainers: the COLLaiTE/Collens project team.
- User community: digital humanities scholars working with TEI-encoded manuscript witnesses and textual variation.

## Decision process

Use issues and pull requests for visible discussion. Significant technical decisions should be summarized in Architecture Decision Records in `docs/decisions/`.

For research-facing decisions, document the scholarly rationale, the affected data model, and any limitations for interpretation.

## Maintainer responsibilities

- Review pull requests.
- Keep tests, documentation, and metadata current.
- Triage issues.
- Maintain release notes and citation metadata.
- Make handover possible for future maintainers.

## Handover

Before a maintainer leaves, update:

- `docs/architecture.md`
- `docs/release.md`
- open issues and milestones
- deployment notes
- known risks and limitations
