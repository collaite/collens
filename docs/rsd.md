# Research Software Directory preparation

Use this checklist when preparing or updating a Research Software Directory entry for Collens.

## Suggested short description

Collens is browser-based research software for visual exploration of textual variation in TEI-encoded manuscript witnesses.

## Suggested long description

COLLaiTE Collens helps digital humanities researchers compare multiple manuscript witnesses, inspect TEI/XML transcription states, keep manuscript images synchronized with text, calculate editorial statistics, and generate CollateX-based collation views. The software is designed as an interpretive interface around textual variation rather than as a replacement for scholarly editorial judgement.

## Keywords

Digital humanities, TEI XML, manuscript collation, textual criticism, digital philology, manuscript studies, CollateX, visualization, SvelteKit, TypeScript.
