# 0001. Record architecture decisions

Date: 2026-07-01

## Status

Accepted

## Context

Collens combines digital humanities research requirements, TEI/XML parsing, browser-based visualization, local storage, and external collation integration. Future maintainers need lightweight records of decisions that affect scholarly interpretation, data handling, deployment, or sustainability.

## Decision

Significant decisions will be recorded as Architecture Decision Records in `docs/decisions/`.

Each ADR should describe the context, decision, consequences, and alternatives considered.

## Consequences

- Major trade-offs become visible to future contributors.
- Research-facing assumptions can be reviewed alongside code changes.
- Handover and paper-writing are easier because rationale is preserved.
