# Project checklist

## Repository hygiene

- [x] README exists.
- [x] Apache 2.0 license exists.
- [x] Citation metadata exists.
- [x] Zenodo metadata exists.
- [x] CodeMeta metadata exists.
- [x] Contributing guide exists.
- [x] Governance guide exists.
- [x] Security policy exists.
- [x] Code of conduct exists.
- [x] Changelog exists.
- [x] Issue and pull request templates exist.
- [x] Metadata validation workflow exists.
- [x] Dependabot configuration exists.

## Before first citable release

- [ ] Confirm author order and contributors.
- [ ] Confirm public demo URL works.
- [ ] Enable Zenodo archiving.
- [ ] Create a GitHub release.
- [ ] Add release DOI to README/CITATION if available.
- [ ] Confirm Research Software Directory entry.

## Before handover

- [ ] Triage open issues.
- [ ] Update architecture notes.
- [ ] Update release notes.
- [ ] Confirm dependency update policy.
- [ ] Confirm maintainer contact route.
