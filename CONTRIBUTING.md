# Contributing

Thank you for considering a contribution to COLLaiTE Collens.

## Ways to contribute

- Report a bug or usability issue.
- Suggest a feature for manuscript comparison, TEI processing, or visualization.
- Improve documentation and examples.
- Add tests for TEI parsing, witness handling, file import, or collation output.
- Review architecture, accessibility, and sustainability decisions.

## Development workflow

1. Open an issue or discuss the change with the maintainers.
2. Create a branch from `main`.
3. Make a small, reviewable change.
4. Add or update tests and documentation when behaviour changes.
5. Run the local checks that are available in your environment:
   - `bun install`
   - `bun run check`
   - `bun run lint`
   - `bun test`
   - `bun run build`
6. Open a pull request using the PR template.

## Pull request expectations

- The purpose of the change is clear.
- Tests or validation steps are included when relevant.
- Documentation is updated when behaviour changes.
- Scholarly assumptions and limitations are documented.
- New dependencies are justified.

## Maintainers

Current project contacts are listed in `CITATION.cff`. For general project questions, use GitHub issues.
